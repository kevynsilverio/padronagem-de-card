# Impactos atuais

Hoje o fluxo DEV → QA sofre com falta de informação no card. Os principais impactos são:

- **QA precisa buscar informações com DEV e PO** para entender o que foi entregue
- **Dúvidas sobre regra de negócio** considerada na implementação
- **Dificuldade para reproduzir o comportamento** sem um passo a passo
- **Retrabalho durante os testes** por critérios de aceite desalinhados com a entrega

## O que a padronização resolve

| Impacto | Como o novo preenchimento ajuda |
| --- | --- |
| QA busca informação fora do card | Resumo da implementação e regra de negócio ficam registrados |
| Dúvida de regra de negócio | Campo obrigatório descreve a regra usada na validação |
| Dificuldade para reproduzir | Passo a passo de execução / reprodução no card de DEV |
| Retrabalho nos testes | Critérios de aceite com `Sim` / `Parcial` / `Não` e justificativa |
